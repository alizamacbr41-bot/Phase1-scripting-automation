# Phase 1 Internship Projects

This repository contains two scripting and automation projects.

## Project 1: System Information Tool

**File:** `system_info.sh`

A Bash script that displays basic Linux system information, including:
- Current date and time
- Hostname
- Operating system
- Kernel version
- CPU information
- Memory usage
- Disk usage

### How to run

```bash
bash system_info.sh
```

## Project 2: Password Generator

**File:** `password_generator.py`

A Python program that generates secure random passwords using Python's `secrets` module.

### How to run

```bash
python3 password_generator.py
```

Generate a 24-character password:

```bash
python3 password_generator.py --length 24
```

## Requirements

- Linux operating system
- Bash
- Python 3

## Purpose

These projects demonstrate basic scripting, automation, and command-line programming skills.
